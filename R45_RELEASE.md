R45 – funkční opravy CRM/Dokumenty/hamburgeru, kalendář, banka, automatizace, exporty, zákaznická administrace a Nia interval.

- Globálně robustnější mobilní hamburger/drawer na všech přihlášených stránkách.
- API klíče odstraněny z běžné navigace; webová stránka API klíčů přesměruje do Nastavení.
- Zakázky: kompaktní tlačítko Nová zakázka.
- Banka: přehled zákazníka u spárovaného dokladu a ruční párování transakce s dokladem.
- Kalendář: měsíční kalendář, navigace měsíců, dnešní datum, události v mřížce a formulář navázaný na zvolené datum.
- Automatizace: vysvětlení principu Událost → Akce a srozumitelnější volby.
- Exporty: nejdříve volba dat a formátu Excel (.xlsx) nebo PDF; Excel je generován jako skutečný XLSX balíček bez závislosti na ZipArchive.
- Administrace pro zákazníka: hlavní vstup vede na Předplatné; AI provider a systémové zálohy nejsou v zákaznickém rozhraní. Vlastní kopie dat je dostupná jako JSON export.
- Interní serverová záloha je omezena na Super Admina.
- Nia: automatická vizuální bublina nejdříve po 30 s a následně maximálně jednou za 5 minut, bez automatického hlasu.
- Nia panel, Dashboard a ostatní funkce nebyly strukturálně měněny.

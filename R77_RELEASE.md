# Byznio R77 – clean invoice email layout

- Opraven textová část e-mailu k faktuře: žádné slepené řádky/štítky.
- Opraveno dvojité „Dobrý den“.
- HTML e-mail používá přehledný blok údajů: doklad, částka, splatnost.
- CTA „Otevřít doklad“ zůstává jako tlačítko v HTML.
- Textová alternativa obsahuje čistě strukturované údaje.
- Použit email PNG logo pro lepší kompatibilitu poštovních klientů.
- .env není součástí release.

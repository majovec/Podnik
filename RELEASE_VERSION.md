# Byznio Release r22

Datum: 2026-09-22

Tato verze navazuje na v21 a obsahuje finální sjednocení UI/Nia vrstvy.

- prémiový dashboard s KPI, financemi, úkoly, pohledávkami, kalendářem, skladem a rychlými akcemi
- Nia jako plovoucí robot s autonomním pohybem
- Nia lze ručně přetáhnout a její pozice se uloží v prohlížeči
- po ručním přesunutí Nia nepřeskočí okamžitě zpět
- kliknutí otevře panel Nii, panel má zavírací tlačítko a zadání úkolu
- Nia má proaktivní briefing a hlasový výstup po interakci
- registrační onboarding má 7 kroků včetně dokončení
- inline založení zákazníka při tvorbě faktury je součástí projektu
- AI provider factory je pod PSR-4 cestou `App\Services\AiProviderFactory`

Build marker: `2026.09.22-r22`
